# Portfolio

Site statique (HTML, CSS, JavaScript), sans installation.

## Structure
- `index.html` : structure de la page (rarement à modifier)
- `js/config.js` : **vos textes, projets, prix et contacts** (le fichier à modifier en premier)
- `js/main.js` : affiche le contenu de `config.js` dans la page
- `css/style.css` : couleurs, polices, mise en page (couleurs en haut, dans `:root`)
- `assets/` : favicon et `images/` pour vos photos et captures de projets

## Tester en local
Double-cliquez sur `index.html`.

## Mettre en ligne (GitHub Pages)
1. Créez un dépôt public nommé `votre-pseudo.github.io`.
2. Envoyez tout le contenu de ce dossier à la racine du dépôt.
3. Settings, Pages, Branch `main`, Save.
4. Le site est disponible sur `https://votre-pseudo.github.io`.

## Ajouter une image à un projet
Placez l'image dans `assets/images/`, puis référencez-la avec `assets/images/nom.jpg`.
